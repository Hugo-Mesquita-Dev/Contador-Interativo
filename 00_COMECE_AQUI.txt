## 💡 Primeiras Mudanças Sugeridas

### Mudar Cor
Procure em `lib/main.dart`:
```dart
seedColor: Colors.blueAccent  // ← Mude para:
seedColor: Colors.green       // Verde
seedColor: Colors.purple      // Roxo
seedColor: Colors.pink        // Rosa
```

### Mudar Nome
Procure em `main()`:
```dart
nomeContador: 'Pontos',  // ← Mude para:
nomeContador: 'Alunos Presentes'
```

### Aumentar Número
Procure em `build()`:
```dart
fontSize: 72  // ← Mude para:
fontSize: 120
```
